# AGENTS.md

`pi-stick` is a Linux CLI for local Docker project workspaces and private GitHub PR reviews.

## Layout

- `pi-stick`, `src/` — Host CLI. Runs directly on Node 24.12+ and bundles with Bun. **Use Node built-ins only** (no npm runtime dependencies).
- `reviewer.ts`, `review-method.md`, `Dockerfile`, `compose.yaml` — Containerized reviewer (runs inside Docker with `@earendil-works/*` dependencies).
- `project-template/` — Scaffold copied verbatim into new project workspaces.
- `scripts/` — Release staging (`stage-release.sh`), Linux binary/npm packaging (`build-linux.sh`, `pack-npm.sh`), interactive installer (`install.sh`), and Biome plugins.
- `test/cli.test.ts` — CLI test suite (`PI_STICK_TEST_BINARY` overrides the binary under test). `test/scripts/install.sh` smoke-tests the installer against the latest GitHub release.

## Verification

- `npm run check` — Biome lint/format check (warnings are errors) and `tsc --noEmit`.
- `npm run lint -- --write` — Apply safe Biome fixes.
- `npm test` — Run `node --test test/*.test.ts`.
- `npm run build:binary` / `npm run pack:npm` — Build release artifacts (uses Bun pinned in `mise.toml`).

Run `npm run check` and `npm test` after changes.

## Conventions

- TypeScript compiles with `strict`, `erasableSyntaxOnly`, `verbatimModuleSyntax`, and `allowImportingTsExtensions`: keep explicit `.ts` import extensions and avoid non-erasable TS syntax (enums, parameter properties).
- Keep `package.json` `"private": true`; public npm manifests are generated by `scripts/pack-npm.sh`.
- If you add, rename, or remove shipped runtime files, update `scripts/stage-release.sh`.
- Keep PR-supplied paths and untrusted repo content isolated: never evaluate them as shell code, and keep credentials out of build contexts, Git, and logs.
